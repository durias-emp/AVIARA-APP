## Suggested Import Settings

- Team: CNA
- Project: PQRH App
- Title column: Title

- Status column: Status

- Labels column: Labels

## Notes

- The import intentionally excludes non-PQRH product notes: hotel outreach, PACO conversation, pilot schedule, and Ukiyo marketing credit.
- If Linear asks whether to create missing labels/statuses, allow it.
- If Linear does not map `Done` cleanly, import completed items into Backlog and mark them Done afterward.
